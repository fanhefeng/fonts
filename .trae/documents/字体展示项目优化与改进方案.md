## 目标
- 降低首屏与总体加载压力、提升交互与可观测性
- 统一代码风格与路径别名，清理未用逻辑
- 优化字体资源格式与下载体验，兼容静态导出与 GitHub Pages

## 变更概览
- 路径与依赖：统一 `@/fonts` 导入；移除未用依赖与工具
- 加载策略：视窗懒加载 + 变体按需、并发受控、失败重试
- 状态与进度：接入全局事件到 `useFontLoading`，显示进度/统计
- 资源治理：优先 `woff2`，中文字体子集化，变体瘦身
- 下载优化：使用真实扩展、批量节流与反馈
- 部署适配：静态导出的 `basePath/assetPrefix` 配置（仅 GH Pages）
- 样式与可达性：减少不必要动画、统一 Token、完善键盘交互

## 实施步骤
### 1. 路径别名统一
- 将 `src/app/page.tsx:3` 的 `import { myFonts, DouyinSans } from "../../styles/fonts"` 修改为 `import { ... } from "@/fonts"`
- 在代码中统一引用字体配置为 `@/fonts`，避免相对路径脆弱性（参考 `tsconfig.json:21-24`）

### 2. 视窗懒加载与并发控制
- 在 `src/components/ui/MyFont.tsx` 为卡片引入 `IntersectionObserver`，仅元素进入视窗时触发该字体加载（包裹现有 `loadFontVariants` 逻辑 `src/components/ui/MyFont.tsx:69-104,153-176`）
- 变体加载并发控制：
  - 先加载当前展示所需的权重/样式（基于 `getFontStyle` 的最终权重/样式 `src/components/ui/MyFont.tsx:270-297`）
  - 其他变体后台分批（如每批 2-3 个，批间 `setTimeout` 50–100ms）
- 将大量 `console.log` 包裹在开发态开关（避免生产噪音）

### 3. 变体按需与降级策略
- 使用已有工具函数：`findClosestWeight/findAvailableStyle/getOnlyAvailableStyle`（`src/utils/fontVariants.ts`）
- 加载失败降级：
  - 权重降级到最接近可用值
  - 样式降级为 `normal`
  - 预览区在失败时仅使用 `var(--font-chinese-fallback)`（已有逻辑 `src/components/ui/MyFont.tsx:281-286`）

### 4. 接入全局加载状态管理
- 在 `MyFont.tsx` 加载周期派发事件：
  - `fontLoadStart`（开始）
  - `fontLoaded`（成功，携带耗时）
  - `fontError`（失败）
- `useFontLoading` 已监听事件（`src/hooks/useFontLoading.ts:106-110`），可在页面顶部增加简洁进度条/统计卡片显示（使用 Antd `Progress` / `Alert`）

### 5. 资源格式优化与中文子集化
- 优先使用 `woff2`：将 `ttf/otf` 大文件按需替换为 `woff2`（已有族示例：`PingFangSC/JetBrainsMono/FiraCode`）
- 为中文字体生成常用字集子集（如简体常用 3K/5K），替换到 `public/fonts` 并更新 `styles/fonts.ts` 的 `src` 路径与 `fontVariantsMap`
- 适度减少不必要的高权重与斜体变体，降低总变体数量与加载/下载压力

### 6. 下载体验与节流
- `downloadFontFile` 已依据变体文件名与扩展生成路径（`src/utils/fontDownload.ts:110-116,92-95`），保持按真实扩展下载，不强制 `ttf`
- 批量下载（`downloadFontFamily`）加入简单节流与进度提示（每次触发 1–2 个并避免 UI 阻塞），并在完成后统一提示
- 失败回退：若 `italic` 文件不存在，自动尝试 `normal`；若权重失败，回退到 `400`（逻辑已具备 `src/utils/fontDownload.ts:199-207`）

### 7. 静态导出与 GitHub Pages 适配（按需）
- 若部署到 `https://<user>.github.io/fonts/`：在 `next.config.mjs` 增加 `basePath: '/fonts'` 与（可选）`assetPrefix: '/fonts'`，统一静态资源路径前缀
- 保持 `images.unoptimized: true` 与 `output: 'export'`（`next.config.mjs:3,10`）
- 现有下载逻辑已处理 GitHub 环境 `getBasePath()`（`src/utils/fontDownload.ts:7-13`），配置后页面与字体引用也保持一致

### 8. 清理未用依赖与工具
- 依赖：移除未使用的 `critters`（`package.json:26`）
- 代码：
  - 若不采用 CSS 变量 + `FontFace` 方案，删除或标注弃用 `src/utils/fontLoader.ts`
  - 抽取公共函数以减少重复（见下一步）

### 9. 样式与无障碍优化
- 为 `prefers-reduced-motion` 降低或移除预览区的过渡动画（参考 `src/components/ui/MyFont.tsx:293-295`）
- 统一色板与 Token（`src/app/global.css:136-178,151-163`），减少高 `z-index` 选择器与交叉覆盖
- 保留现有 `aria-label`，补充键盘操作提示与焦点样式，提升可达性

### 10. 抽象公共工具
- 在 `src/utils/` 新增工具函数：
  - `getFontFamilyName(font)`：封装 `style.fontFamily` 的提取（用于 `page.tsx` 与 `MyFont.tsx`）
  - 轻量并发控制器（如基于队列）供变体批量加载与批量下载使用
